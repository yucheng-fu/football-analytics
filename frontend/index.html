How this is calculated

SHAP values. Each bar represents the Shapley value of a feature. Read more about how Shapley values are used to interpret machine learning models in this blog post.

Baseline. "Average pass" is the mean predicted success probability of the model over 200 real passes sampled from the training data.

Features. Some features in the chart cannot be set directly in the UI, as they are engineered features derived from the pass properties and the drawn start and end points.

Method. The SHAP values are obtained using the permutation explainer with 200 passes as the reference. Starting from the reference passes, the features of this pass are switched in one at a time following a random permutation, recording the change in predicted success probability at each step. Averaging these changes over many random permutations gives each feature's SHAP value.

Reading the numbers. Each number is the change in success probability attributed to that feature in percentage points (pp). Starting from the average pass and adding every effect gives exactly the prediction for this pass: average + all effects = this pass.
